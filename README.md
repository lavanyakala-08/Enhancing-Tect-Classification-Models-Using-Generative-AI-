# 🤖 End-to-End Workflow for Enhancing Text Classification Models Using Generative AI

A Python-based Generative AI project that demonstrates an end-to-end workflow for text classification using Natural Language Processing (NLP) and a BERT model. The project preprocesses text, trains a classification model, and predicts the category of new input through a Flask web interface.

---

## 📌 Features

- Text Preprocessing
- Data Cleaning
- Tokenization
- BERT-based Text Classification
- Model Training
- Prediction on New Text
- Flask Web Interface
- End-to-End AI Workflow

---

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Text-Classification-Generative-AI.git
```

Move to the project directory

```bash
cd Text-Classification-Generative-AI
```

Install the required libraries

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Train the model

```bash
python train.py
```

Start the Flask application

```bash
python app.py
```

Run prediction

```bash
python predict.py
```
